# 【崩坏：星穹铁道】星穹列车 —— EU5 mod 实施计划（v1 草案）

> 游戏版本 1.3.11；依赖创意工坊「二向箔 / 2D Portrait Framework」（本地 3599699279）。
> mod 直接构建于 `StarRail/`；文档/临时文件在 `临时文件/`（不进 git 发行）。
> 参考：`00_主题映射与命名规范.md`、`RhodeIsland/临时文件/` 全套 DvT 框架文档。

## 1. 架构总述

星铁版 **同时参考 DvT(原神) 与 RI(明日方舟)**：
- **机制骨架**照 RI（现代结构：单文化、无附庸、无皮肤、HSR_ 前缀、拆分文件）。
- **宗教系统**照 DvT **恢复**——命途=星神信仰，是 RI 砍掉的部分，星铁要保留。
- **属性(元素)**照 DvT——7 属性标签，对应原神 7 元素。
- **出身**照 RI——阵营/出身地标签。
- **主题轴心** = 探索/殖民（EU5 原生，见 §5）。

## 6. 命途宗教系统（18 命途，仅角色风味）

宗教组 `Aeons`，**18 个命途信仰**（清单见 00 文档 §3；依据 CK3 mod 236850/3483671512）。**仅作角色宗教风味**：
- `religions/Aeons.txt`：18 个 `*_Worship` 宗教定义（color = 该命途色，group = Aeons，tags = { astral_gfx }）。
- 角色 `religion` 字段 = 某命途（e.g. `Hunt_Worship`）。
- **不做**：皈依行动 / 省份传教 cabinet_action / 星神内阁判断 / 宗教 GUI / 宗教背景图 / 转命途。

> 说明：崩铁无法把「星神」当内阁总管（对标原神的 Archon），故皈依类玩法整体舍弃；命途信仰只作为角色归属标签与 loc 展示。

## 9. 决策记录（已敲定）

1. 命途宗教：**18 个，仅角色风味，不做皈依系统**。
2. 主题轴心：**`can_colonize = yes` + 殖民增益**。
3. 不做星神化身（不做皈依故无需）。
4. 「开放者」阶层 / 「星穹列车」IO 名据此定（可再改名）。
5. 抽卡定价：**1600 星琼/次**（货币与 DvT 原神完全一致）。
